## Кратко: суть затеи

Хартия 5.0 — это не описание «идеального общества» и не манифест. Это **открытая операционная система для цивилизации**, в которой:

- **Базовые блага безусловны.** Жильё, питание, здравие, образование, связь и безопасность не являются наградой за лояльность, должность или высокий Поток.
- **Поток — не деньги.** Это счётчик вовлечённости и подтверждённого вклада, который нельзя обменять на базовые блага или превратить в социальный ранг.
- **Власть — временный мандат.** Ротация, минимальный управленческий слой и запрет на превращение ответственности в привилегию.
- **Решения проверяемы.** Сигнал → Всеобщий прогон → Коннект → План реализации → ОТК → Верификация → архив Хранителей.
- **Ошибка — не повод для репрессий, а сигнал для улучшения.** Наказание — только за систематическое нарушение процедур.
- **Переходный период изолирован.** Внешние деньги, армия и дипломатия живут в отдельном 15-м направлении — «Шлюзе», который не проникает во внутренний контур 14 направлений.
- **Текст проверяется кодом.** В ядре XartIA уже реализованы задачи, ОТК, Поток, казна, мандаты, Совет, Шлюз и профессиональный паспорт.

Главная идея: **цивилизация должна уметь обнаруживать и исправлять собственные ошибки быстрее, чем они накапливаются.**

## Подробнее: как это работает

### 1. Базовые блага отделены от активности

Каждый участник имеет безусловное право на базовый стандарт достаточности. Он не зависит от величины Потока, должности, мандата или выражения несогласия. Блага нельзя отнять как наказание за низкую активность или критику Хартии.

Проектные ресурсы сверх личного стандарта выделяются только под утверждённый План реализации и только по тройной подписи: Совет направления + Балансировка + независимый аудитор Верификации.

### 2. Поток — мера движения, а не валюта

Поток отражает выполнение задач, участие в Советах, обучение, рефлексию и творчество. Он не обменивается на базовые блага и не создаёт привилегий. Прямое социальное ранжирование по балансу Потоков запрещено.

### 3. Власть не задерживается

Мандаты временны. Управленцев — 2–5% от числа исполнителей. После мандата человек возвращается к профессиональной деятельности. Для Шлюза действуют отдельные жёсткие правила ротации.

### 4. Решения проходят через проверяемый цикл

1. **Сигнал** — проблема, идея или сбой.
2. **Префильтрация** — проверка формата и этикета.
3. **Всеобщий прогон** — ответы заинтересованных Советов.
4. **Коннект** — выяснение причины профессиональных расхождений.
5. **План реализации** — задачи, сроки, критерии приёмки, контрольные точки.
6. **ОТК** — приёмка результата.
7. **Верификация** — аудит процедур и выборочная перепроверка.
8. **Хранители** — фиксация истории.
9. **Ретроспектива** — сбой становится материалом для улучшения.

Арбитраж не выбирает «правый» Совет. Он разрешает только процедурные конфликты.

### 5. Переходный Шлюз изолирован

Пока внешний мир живёт на деньгах, власти и дефиците, существует 15-е направление — «Внешний шлюз». Оно конвертирует внешние ресурсы, ведёт дипломатию и оборону, принимает внешние активы.

Но:

- Шлюз временен;
- его власть не проникает в 14 направлений;
- его цифровая инфраструктура физически изолирована;
- внешние деньги не конвертируются во внутренние Потоки;
- каждые 5 лет — пересмотр, через 50 лет — референдум о роспуске.

### 6. Развитие идёт через кванты, а не через «великий план»

Квант — минимальная автономная единица развития, которую можно скопировать, адаптировать, измерить, улучшить и снова тиражировать. Обнаружение → аудит → тест → масштабирование → архив. Избыточное производство создаёт резерв для новых общин и кризисов.

## Что уже работает в ядре XartIA

Это не только текст. В репозитории [vamhana/xartia](https://github.com/vamhana/xartia) уже реализованы и проверены ключевые контуры.

| Контур | Что проверено |
|---|---|
| **Задачи и Поток** | Заявка → участник → задача → отчёт с артефактом → ОТК → Поток. ✅ CI |
| **Мандаты** | Срок, ротация, отзыв, повторная выдача. ✅ тест инвариантов |
| **Пересмотр** | Пересмотр принятой задачи и обратная проводка Потока. ✅ тест |
| **Казна** | Пол 1.00, распределение 60/30/10, 3 подписи из 5, выкуп, покупка/дар. ✅ тест казны |
| **Шлюз** | Права, состояния, гонка одобрений, идемпотентность. ✅ тест контура |
| **Совет направления** | Выборы, ротация 180 дней, дисквалификация. ✅ тест Совета |
| **Webhooks** | Подписки, доставки, повтор, ротация секрета. ✅ тест + UI |
| **Паспорт: каталог** | 54 атома в 7 кластерах + 3 профиля + 17 направлений. ✅ test-passport-v2 |
| **Паспорт: измерения** | 5 измерений U/X/D/P/E, шкала 0..9, `0 ≠ null`, ширина и глубина раздельно. ✅ test-passport-v2 |
| **Паспорт: права и апелляции** | Матрица прав, апелляции, disputed, stale. ✅ test-passport-v3 |
| **Паспорт: связи** | TaskProfile, TeachingRelation, Matching. ✅ test-passport-v4 |
| **Паспорт: допуски** | Permit, mentor_questions. ✅ test-passport-v5 |
| **Паспорт: команды** | TeamCapability, practice_review_policy, cron. ✅ test-passport-v6 |
| **Паспорт: калибровка** | Anchors, sessions, report, SVG-граф. ✅ test-passport-v7 |
| **Паспорт: версии** | criteria_version, semver bump, advisory lock. ✅ test-passport-v8 |
| **Каталог** | Workflow предложений, CYB.ATOM.0055, anchor'ы. ✅ test-catalog-v04 |

**Профессиональный паспорт** — это не резюме и не рейтинг. Это доказательная проекция человека на общую решётку проверяемых компетенций:

- **Атомы** — минимальные независимо проверяемые способности.
- **Пять измерений:** Понимание (`U`), Объяснение (`X`), Проектирование (`D`), Выполнение (`P`), Оценка (`E`).
- **Ширина и глубина раздельно.** Среднее пяти измерений запрещено.
- **История append-only.** Оценку ставит уполномоченный проверяющий; свою работу оценивать нельзя.
- **Приватность по умолчанию закрыта.** Публичный профиль — только по согласию.

Подробная карта «принцип Хартии → модуль → тест» — в [docs/charter-implementation-map.md](https://github.com/vamhana/xartia/blob/main/docs/charter-implementation-map.md).

## Карта текста Хартии

- **Книга I. Основы и архитектура** — преамбула, неизменяемое ядро, идентификаторы, 17 направлений, ячейки N×5, роли.
- **Книга II. Процессы и процедуры** — жизненный цикл сигнала, Всеобщий прогон, Коннект, План реализации, ОТК, материализация благ, сбои, избыточное производство.
- **Книга III. Управление и контроль** — Балансировка, Верификация, Жюри случайной выборки, Инженерия Обнуления, Хранители.
- **Книга IV. Развитие и самокоррекция** — новые профессии, пятилетний пересмотр, кванты, самообнаружение ошибок, контролируемые вызовы, конвергенция, масштабирование.
- **Книга V. Человек, сообщества и внешний мир** — путь участника, мастерство, нулевое наследство, защита от концентрации власти, Шлюз, множественность сообществ, конвергенция государств.
- **Книга VI. Экстренные режимы и безопасность** — Красный Контур, Стальной Колокол, Квант оружия угрозы, ПТТ, Квант стихийной адаптации.
- **Книга VII. Заключительные положения** — языковой протокол, санкции, порядок изменения Хартии, заключительные принципы.
- **Книга VIII. Экспериментальные протоколы** — общие принципы и протокол «Цифровое ядро Первой сотни».

## Как обновить контент

1. Править `charter.md` — не README.
2. Выполнить:
   ```bash
   python scripts/parse_readme.py --force
   ```
3. Если структура книг/частей изменилась:
   ```bash
   python scripts/step_04_charter_pages.py
   ```
4. Закоммитить:
   - `charter.md`
   - `src/content/charter/`
   - `src/pages/charter/`
5. Push в `main` → GitHub Actions задеплоит сайт.
