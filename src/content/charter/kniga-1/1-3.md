(из Приложения, Часть I)
1.3.1. Любая единица системы (человек, группа, задача) имеет уникальный читаемый идентификатор.
1.3.2. Идентификаторы строятся по единому принципу и не требуют переименования при росте системы.
1.3.3. Каждый участник принадлежит одному направлению (1–17), но может временно выполнять задачи в любом другом.
1.3.4. Система управления — минималистичная: число управленцев не превышает 2–5% от общего числа исполнителей, оптимизируется автоматически.
1.3.5. Любой план утверждается только после сквозной экспертизы всех заинтересованных направлений.
1.3.6. Сбой при реализации — не повод для наказания, а сигнал для улучшения системы.
