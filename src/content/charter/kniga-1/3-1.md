3.1.1. Формат: <Буква><5 цифр>-<номер направления>[:<поднаправление>]
— Буква (А–Я) — волна входа (поколение), необязательна.
— 5 цифр (00000–99999) — уникальный номер внутри волны.
— Номер направления (1–17) — основное направление участника.
— Поднаправление (опционально) — уточнение профессии.
3.1.2. Примеры:
— А00001-1 — первый участник, Жизнеобеспечение.
— Б12345-14 — участник из Знания и Образования.
— В98765-6:3 — Ноология, Семантический Страж.
3.1.3. Правила:
— ID неизменен на всю жизнь.
— Участник может иметь псевдоним для общения.
— При временной работе в другом направлении ID не меняется.
