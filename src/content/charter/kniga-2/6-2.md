План реализации утверждён (содержит цель, материальную или нематериальную).
Декомпозиция на дневные задачи для ячеек и исполнителей.
Ресурсное обеспечение — выделение необходимых ресурсов (материалы, время, интеллектуальный труд, экспериментальные мощности).
Исполнение:
для материальных благ — производство, строительство, создание объекта;
для нематериальных — проведение исследований, разработка программ, обучение, создание прототипов, моделирование, написание кода, проведение экспериментов.
Контроль качества — проверка соответствия утверждённым стандартам:
для материальных — физические измерения, испытания;
для нематериальных — экспертиза (Ноология, Верификация), проверка воспроизводимости, оценка влияния на систему (Балансировка), рецензирование (Трансляция, Знание).
Приёмка — комплексная с участием всех заинтересованных направлений:
для материальных — акт приёма-передачи, маркировка, регистрация в реестре;
для нематериальных — акт внедрения или признания: фиксация в архиве, включение в образовательные программы, изменение стандартов, ввод в эксплуатацию, публикация протокола.
Передача участнику (или системе):
для материальных — физическая передача, регистрация права пользования;
для нематериальных — интеграция в общую среду (библиотека, производственные процессы, защитные протоколы, энергетические стандарты) без необходимости индивидуального «получения».
Обратная связь и измерение эффекта — сбор данных о влиянии блага на качество жизни, безопасность, развитие. Для нематериальных — измерение через мета-потоки (скорость решений, обученность, снижение уязвимости, экономия ресурсов).
